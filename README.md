# [我们爱上的，究竟是真人，还是“人设”？](https://hoo.be/heiliaozxk)
我们爱上的，究竟是真人，还是“人设”？
在见面之前，我们早已翻遍了对方的朋友圈、微博、小红书。我们看到了一个热爱生活、品味不俗、积极向上的“他/她”。这个在社交媒体上精心构建的“人设”，先于真人进入了我们的内心。

于是，恋爱变成了一场“人设”与“本我”的博弈。我们害怕暴露那个会懒散、会焦虑、会有负能量的真实自己，同时也害怕发现对方的“人设”崩塌。我们在线上扮演完美情人，在线下却疲惫不堪。

启示： 健康的爱情，必须发生在两个“真人”之间。它需要你鼓起勇气，慢慢卸下伪装，也允许对方展露脆弱。爱那个在朋友圈里闪闪发光的人，是本能；爱那个在深夜里崩溃哭泣、素颜朝天的普通人，才是选择。去爱一个具体的人，而非一个完美的符号。
